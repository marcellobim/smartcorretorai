# SMARTCORRETORAI 3.0 UX BLUEPRINT

## Princípios de Experiência

O SmartCorretorAI 3.0 deve combinar dois modelos mentais fortes:

- CapCut: biblioteca visual, previews, exemplos prontos, sensação de criação rápida e resultado concreto.
- ChatGPT: campo livre, conversa guiada, interpretação de intenção e recomendação inteligente.

Princípios obrigatórios:

- O Cadastro Mestre é o cérebro do sistema.
- Conta não é a mesma coisa que marca.
- O usuário é leigo e não deve entender tecnologia, formatos, APIs, modelos ou templates.
- A interface deve mostrar resultados, não tecnologia.
- Segurança deve existir desde a concepção.
- Dados devem ser reutilizados sempre que possível.
- O corretor deve fazer o menor esforço possível.
- A Biblioteca Profissional continua sendo produto estratégico.
- A IA deve guiar o usuário, reduzir dúvidas e sugerir próximos passos.

## 1. Landing Pública

A landing pública é a primeira impressão do SmartCorretorAI 3.0.

Ela deve vender transformação, não funcionalidades isoladas.

Objetivo:

- mostrar que o corretor consegue criar marketing imobiliário profissional em poucos minutos;
- comunicar valor antes de explicar produto;
- encantar visualmente;
- gerar desejo de experimentar;
- mostrar exemplos reais.

Experiência recomendada:

- hero visual com exemplos de campanhas;
- vídeos curtos mostrando materiais prontos;
- previews de peças e páginas;
- chamadas por intenção, não por tecnologia;
- prova visual de resultado;
- linguagem simples e comercial.

Pergunta central:

> O que você deseja criar hoje?

Entradas sugeridas:

- Divulgar um imóvel;
- Criar campanha completa;
- Gerar imagem premium;
- Transformar fotos em vídeo;
- Criar landing do imóvel;
- Preparar materiais para redes sociais.

O usuário não deve começar escolhendo API, formato, resolução ou template. Ele deve começar pelo resultado que deseja.

## 2. Primeiro Login

O primeiro login deve ser acolhedor, guiado e direto.

Objetivo:

- tirar o usuário da tela vazia;
- reduzir ansiedade;
- explicar o sistema sem tutorial longo;
- conduzir para o primeiro resultado.

Fluxo recomendado:

1. Boas-vindas.
2. Pergunta simples: "Vamos criar marketing para qual imóvel?"
3. Início do Cadastro Mestre.
4. Recomendação automática da IA.

Evitar:

- dashboards vazios;
- menus complexos;
- termos técnicos;
- muitas decisões antes do primeiro resultado.

Mensagem conceitual:

> Cadastre o imóvel uma vez. A IA transforma esse cadastro em campanhas, imagens, vídeos e páginas.

## 3. Cadastro Mestre

O Cadastro Mestre é o núcleo operacional do SmartCorretorAI.

Ele deve concentrar os dados reutilizáveis do imóvel e alimentar todos os produtos.

Dados principais:

- tipo do imóvel;
- finalidade;
- localização;
- preço;
- área;
- dormitórios;
- suítes;
- vagas;
- fotos;
- destaques;
- observações;
- dados comerciais relevantes.

Função estratégica:

- evitar repetição de cadastro;
- manter consistência entre produtos;
- melhorar a qualidade da IA;
- reduzir esforço do corretor;
- permitir geração multicanal a partir de uma única fonte.

Retenção:

- dados disponíveis por 15 dias;
- após esse período, o sistema pode solicitar revisão ou novo cadastro.

Experiência ideal:

- campos simples;
- ajuda contextual;
- seleção por chips quando possível;
- upload claro;
- validações amigáveis;
- indicação de progresso;
- reaproveitamento automático nos produtos.

## 4. Perfil Comercial

O Perfil Comercial representa a identidade profissional usada nas entregas.

Conta não é marca.

A conta identifica o usuário. A marca define como o corretor aparece nos materiais.

Dados do Perfil Comercial:

- nome profissional;
- WhatsApp;
- e-mail;
- CRECI, quando informado;
- logo ou marca;
- imobiliária;
- cores ou preferência visual, quando aplicável;
- assinatura comercial;
- foto profissional, quando aplicável.

Regras:

- não inventar CRECI;
- não criar dados profissionais fictícios;
- não expor telefone/e-mail em logs;
- permitir atualização simples;
- reutilizar esses dados nos produtos quando fizer sentido.

Objetivo:

- garantir consistência de marca;
- profissionalizar as peças;
- evitar preenchimento repetido;
- separar autenticação de identidade comercial.

## 5. Home Pós Login

A home pós login deve ser uma central de criação.

Ela não deve parecer um painel administrativo frio.

Objetivo:

- mostrar caminhos claros;
- sugerir próximos passos;
- reaproveitar imóveis recentes;
- destacar produtos principais;
- reduzir decisões.

Estrutura recomendada:

- chamada principal: "O que você quer criar hoje?";
- imóveis recentes do Cadastro Mestre;
- botões de criação rápida;
- Biblioteca Profissional;
- produtos IA premium;
- histórico recente;
- saldo/Smart Tokens quando aplicável.

Entradas principais:

- Criar com IA;
- Hero IA;
- Campanha IA Premium;
- Transformar Meu Vídeo;
- Landing IA;
- Banners Rápidos;
- Biblioteca Profissional.

A IA deve sugerir:

- "Você já tem um imóvel cadastrado. Quer gerar uma campanha?";
- "Este imóvel tem boas fotos. Recomendamos Hero IA.";
- "Para este imóvel, uma landing pode ajudar a captar leads."

## 6. Biblioteca Profissional

A Biblioteca Profissional continua sendo produto estratégico.

Ela representa o lado CapCut da plataforma: visual, concreto, rápido e confiável.

Objetivo:

- mostrar variedade;
- gerar sensação de valor;
- permitir escolha visual;
- entregar peças estáveis;
- manter opção prática para usuários que preferem controle.

Princípios:

- previews reais;
- modelos organizados;
- nomes comerciais claros;
- sem formatos técnicos como decisão principal;
- botão de visualização;
- seleção simples;
- limite operacional claro;
- preço/créditos transparentes.

Banners Rápidos faz parte da Biblioteca Profissional e deve permanecer estável.

A Biblioteca não deve competir com a IA premium. Ela deve ser uma base confiável para criação rápida e previsível.

## 7. Hero IA

Hero IA é o produto de imagem premium.

Objetivo:

- gerar uma imagem de impacto;
- elevar percepção de valor;
- criar uma peça principal para divulgação;
- funcionar como "capa" visual de campanha.

Experiência:

1. Usuário seleciona ou cadastra imóvel.
2. IA sugere direção visual.
3. Usuário escolhe estilo.
4. Sistema gera imagem premium.
5. Usuário revisa, baixa e reutiliza.

UX esperada:

- visual sofisticado;
- exemplos antes de gerar;
- poucas decisões;
- linguagem de resultado;
- segurança no uso de fotos e dados.

## 8. Criar com IA

Criar com IA é o campo livre estilo ChatGPT.

Objetivo:

- permitir que o corretor diga o que quer em linguagem natural;
- transformar intenção em entrega;
- funcionar como porta de entrada flexível.

Exemplos:

- "Crie uma campanha para vender este apartamento";
- "Quero um texto para WhatsApp";
- "Faça uma chamada para captar leads";
- "Crie um post para imóvel de alto padrão";
- "Sugira a melhor campanha para este imóvel".

Comportamento esperado:

- entender o Cadastro Mestre;
- fazer perguntas quando faltar dado essencial;
- sugerir produtos;
- gerar textos ou direcionar para fluxos visuais;
- explicar próximos passos de forma simples.

Esse produto deve representar o lado ChatGPT da plataforma.

## 9. Transformar Meu Vídeo

Transformar Meu Vídeo é o produto para reaproveitar vídeos e fotos enviados pelo corretor.

Objetivo:

- transformar material bruto em peça profissional;
- reduzir trabalho de edição;
- entregar vídeo pronto para divulgação.

Fluxo:

1. Usuário seleciona imóvel.
2. Envia vídeo ou fotos.
3. Escolhe objetivo.
4. IA sugere estrutura.
5. Sistema gera vídeo.
6. Usuário revisa e baixa.

UX:

- upload simples;
- status claro;
- exemplos de resultado;
- linguagem focada em divulgação;
- evitar termos técnicos de edição.

## 10. Landing IA

Landing IA gera uma página individual do imóvel.

Objetivo:

- transformar o Cadastro Mestre em uma página de apresentação e captação;
- apoiar campanhas pagas;
- gerar leads;
- facilitar compartilhamento.

Conteúdo:

- fotos;
- descrição;
- diferenciais;
- localização;
- CTA;
- formulário ou botão de contato;
- identidade comercial do corretor.

Experiência:

1. Usuário escolhe imóvel.
2. IA monta estrutura.
3. Usuário revisa.
4. Sistema publica ou gera link.
5. Leads são direcionados ao corretor.

Regras:

- respeitar ownership;
- proteger URLs privadas;
- não expor dados sensíveis desnecessários;
- permitir despublicar ou expirar página.

## 11. Briefing Inteligente

O Briefing Inteligente é a camada que transforma dados soltos em estratégia.

Objetivo:

- interpretar imóvel, público e objetivo;
- sugerir produto ideal;
- orientar linguagem;
- reduzir escolhas manuais.

Entradas:

- Cadastro Mestre;
- Perfil Comercial;
- objetivo do corretor;
- fotos disponíveis;
- padrão do imóvel;
- canal desejado.

Saídas:

- recomendação de produto;
- perfil de campanha;
- tom de voz;
- argumentos principais;
- CTA sugerido;
- próximos passos.

O Briefing Inteligente deve funcionar de forma discreta. O usuário não precisa saber que há uma etapa técnica. Ele deve sentir que a IA entendeu o imóvel.

## 12. Smart Tokens

Smart Tokens representam a futura camada flexível de consumo.

Objetivo:

- simplificar uso entre produtos diferentes;
- permitir custos variáveis;
- reduzir fricção de compra;
- preparar o sistema para produtos IA premium.

Princípios:

- frontend nunca decide saldo;
- frontend nunca decide custo;
- consumo sempre server-side;
- operações idempotentes;
- transparência para o usuário;
- proteção contra abuso.

Na UX, Smart Tokens devem ser explicados de forma simples:

> Use seus Smart Tokens para criar imagens, vídeos, campanhas e páginas.

Não detalhar complexidade técnica para o usuário.

## 13. Jornada Completa do Usuário

Jornada ideal:

1. Usuário acessa a landing pública.
2. Entende rapidamente que a plataforma cria marketing imobiliário com IA.
3. Cria conta.
4. Confirma e-mail.
5. Faz primeiro login.
6. Preenche Cadastro Mestre do imóvel.
7. Completa Perfil Comercial.
8. Escolhe objetivo ou escreve no Criar com IA.
9. IA recomenda produto ou campanha.
10. Usuário visualiza exemplos/previews.
11. Usuário confirma geração.
12. Sistema cria materiais.
13. Usuário revisa, baixa, compartilha ou publica.
14. Dados do imóvel ficam reutilizáveis por 15 dias.
15. Sistema sugere próximos materiais com base no mesmo imóvel.

Princípio final:

> O corretor não deve operar ferramentas. O corretor deve informar o imóvel e o objetivo. A IA organiza o marketing.

O SmartCorretorAI 3.0 deve entregar uma experiência em que o usuário sente que tem uma equipe de marketing imobiliário trabalhando com ele, sem precisar entender design, copywriting, vídeo, tráfego, landing pages ou tecnologia.
