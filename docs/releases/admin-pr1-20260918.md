## Correção do empacotamento Windows antes da publicação

A tentativa inicial foi interrompida antes da Edge Function/promoção: Expand-Archive do Windows PowerShell 5 falhou com caminhos longos e não retornou erro terminante. A extração foi substituída por um helper PowerShell 7/.NET moderno com ErrorActionPreference Stop, destino obrigatoriamente vazio e sem limpeza/deleção. A prova agora confere a existência e o hash Git de cada arquivo esperado na árvore do SHA, tanto no pacote frontend quanto no pacote Edge, antes de enviar. Arquivo ausente ou alterado bloqueia a publicação.

A extração local do pacote anterior foi validada com todos os 538 arquivos. O novo teste rejeita arquivo ausente, modificado, árvore vazia e caminho externo. Em Windows, POWERSHELL_CLI pode apontar para o PowerShell 7 instalado; o padrão é pwsh. Nenhuma trava foi removida. A tentativa remota incompleta ficou sem promoção; o candidato corrigido exige novo checkpoint e todas as verificações oficiais.
`git archive` usa `core.autocrlf=false` apenas nesta operação para preservar os bytes dos blobs Git; a configuração global e os trabalhos paralelos permanecem intactos.
