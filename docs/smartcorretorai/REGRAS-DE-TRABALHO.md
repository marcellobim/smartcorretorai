# Regras De Trabalho

## Regras Gerais

- Nao fazer commit sem autorizacao.
- Nao fazer push sem autorizacao.
- Nao fazer deploy sem autorizacao.
- Nao alterar frontend fora de uma missao explicita.
- Nao alterar Supabase fora de uma missao explicita.
- Nao mexer no Produto 3 atual fora de uma missao explicita.
- Nao remover Creatomate.

## Ao Trabalhar No Smart Motion Engine

- Manter implementacao local enquanto nao houver missao de integracao.
- Nao criar Edge Function antecipadamente.
- Nao integrar StudioHero antecipadamente.
- Nao misturar polling Creatomate com jobs locais do Motion Pipeline.
- Validar localmente com FFmpeg quando solicitado.
- Registrar outputs e reports locais.

## Ao Trabalhar Em Documentacao

- Nao alterar codigo funcional.
- Documentar checkpoint, status e restricoes.
- Separar claramente fatos verificados de planos futuros.

## QA Visual

- Nao inventar avaliacao visual.
- Se os videos nao forem assistidos, criar checklist para revisao manual.
- Registrar criterios de ritmo, CTA, sensacao visual, aparencia de PowerPoint e potencial para preview.
