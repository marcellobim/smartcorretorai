# 🔐 Configuração Meta for Developers — Instagram API

## 📋 Visão Geral

Este guia detalha todas as etapas necessárias para configurar a integração com a **Meta Graph API** e permitir que o SmartCorretor AI publique automaticamente posts e reels no Instagram Business dos corretores.

---

## 🎯 Pré-requisitos

### Para o Desenvolvedor (Você)
1. Conta no [Meta for Developers](https://developers.facebook.com/)
2. App criado no Meta for Developers
3. Acesso ao Railway Dashboard (para configurar variáveis de ambiente)

### Para o Usuário Final (Corretor)
1. **Conta do Instagram convertida para Comercial ou Criador**
   - Acesse o perfil do Instagram → Configurações → Conta → Mudar tipo de conta
   - Escolha "Conta Comercial" ou "Conta de Criador"

2. **Página do Facebook vinculada ao Instagram**
   - No Instagram: Configurações → Empresa → Página do Facebook
   - Vincule ou crie uma Página do Facebook
   - A Página precisa ser administrada pelo mesmo usuário

## 🏗️ Parte 1: Configuração no Meta for Developers

### 1.1 Criar/Acessar o App

1. Acesse [developers.facebook.com/apps](https://developers.facebook.com/apps)
2. Se ainda não criou, clique em **"Criar App"**
   - Tipo: **"Empresa"** ou **"Consumidor"**
   - Nome do App: `SmartCorretor AI` (ou o nome que preferir)
   - Email de contato: seu email

3. Anote o **App ID**: `1166177798972049` (já configurado no CLAUDE.md)

### 1.2 Adicionar Produto Instagram

1. No painel do App, vá em **"Adicionar Produto"**
2. Localize **"Instagram"** e clique em **"Configurar"**
3. Também adicione **"Facebook Login"** (necessário para OAuth)

### 1.3 Configurar Facebook Login

1. No menu lateral, vá em **"Facebook Login" → "Configurações"**
2. Em **"URIs de redirecionamento OAuth válidos"**, adicione:
   ```
   https://smartcorretorai-production.up.railway.app/api/social/instagram/callback
   http://localhost:3001/api/social/instagram/callback
   ```
3. Salve as alterações

### 1.4 Configurar Permissões do App

1. No menu lateral, vá em **"Permissões e Recursos do App"**
2. Solicite as seguintes permissões (clique em **"Solicitar Acesso Avançado"**):

   #### ✅ Permissões Necessárias:
   
   | Permissão | Descrição | Uso no App |
   |-----------|-----------|------------|
   | `instagram_basic` | Acesso básico ao perfil Instagram | Obter username e ID da conta |
   | `instagram_content_publish` | Publicar conteúdo no Instagram | Postar imagens, vídeos e reels |
   | `pages_show_list` | Listar Páginas do Facebook | Encontrar a Página vinculada ao Instagram |
   | `pages_read_engagement` | Ler dados da Página | Acessar token da Página para publicação |

3. Para cada permissão:
   - Clique em **"Solicitar Acesso Avançado"**
   - Preencha o formulário explicando o uso (veja modelo abaixo)
   - Aguarde aprovação da Meta (pode levar 1-3 dias úteis)

#### 📝 Modelo de Justificativa para Permissões:

```
App Name: SmartCorretor AI
Use Case: Real Estate Marketing Automation

Description:
Our SaaS platform helps real estate agents automatically generate and publish 
marketing content (images, videos, and reels) to their Instagram Business accounts. 

- instagram_basic: To identify the user's Instagram Business account
- instagram_content_publish: To post generated marketing content (property listings)
- pages_show_list: To find the Facebook Page linked to the Instagram account
- pages_read_engagement: To obtain the Page access token required for publishing

All content is generated by the user and published to their own accounts only.
```

### 1.5 Obter App Secret

1. No menu lateral, vá em **"Configurações" → "Básico"**
2. Localize **"Chave Secreta do App"** (App Secret)
3. Clique em **"Mostrar"** e copie o valor
4. **⚠️ IMPORTANTE**: Nunca compartilhe ou commite esta chave no GitHub!

### 1.6 Modo de Desenvolvimento vs Produção

- **Desenvolvimento**: Apenas você e testadores adicionados podem usar o app
- **Produção**: Qualquer usuário pode conectar sua conta

Para colocar em produção:
1. Vá em **"Configurações" → "Básico"**
2. Role até **"Modo do App"**
3. Clique em **"Ativar Modo Ativo"**
4. Complete os requisitos (URL de Política de Privacidade, Termos de Serviço, etc.)

## 📡 Parte 4: Rotas da API

### 4.1 Conectar Instagram

**GET** `/api/social/instagram/connect`

Headers:
```
Authorization: Bearer {jwt_token}
```

Response:
```json
{
  "success": true,
  "data": {
    "url": "https://www.facebook.com/dialog/oauth?..."
  }
}
```

O frontend deve redirecionar o usuário para esta URL.

### 4.2 Callback OAuth (automático)

**GET** `/api/social/instagram/callback?code=...&state=...`

Esta rota é chamada automaticamente pelo Facebook após autorização.
Redireciona de volta para o frontend com status de sucesso/erro.

### 4.3 Verificar Status da Conexão

**GET** `/api/social/instagram/status`

Headers:
```
Authorization: Bearer {jwt_token}
```

Response:
```json
{
  "success": true,
  "data": {
    "conectado": true,
    "username": "corretor_exemplo",
    "expira_em": "2026-08-14T12:00:00.000Z"
  }
}
```

### 4.4 Publicar Post/Reel

**POST** `/api/social/instagram/post`

Headers:
```
Authorization: Bearer {jwt_token}
Content-Type: application/json
```

Body (Post com imagem gerada):
```json
{
  "campaign_id": "uuid-da-campanha"
}
```

Body (Reel com vídeo do Creatomate):
```json
{
  "campaign_id": "uuid-da-campanha",
  "video_url": "https://cdn.creatomate.com/renders/...",
  "is_reel": true,
  "cover_url": "https://cdn.creatomate.com/renders/.../thumbnail.jpg",
  "share_to_feed": true
}
```

Response:
```json
{
  "success": true,
  "data": {
    "post_id": "17895695668004550",
    "type": "reel",
    "message": "Reel publicado com sucesso no Instagram!"
  }
}
```

### 4.5 Desconectar Instagram

**DELETE** `/api/social/instagram/disconnect`

Headers:
```
Authorization: Bearer {jwt_token}
```

Response:
```json
{
  "success": true,
  "data": {
    "message": "Instagram desconectado com sucesso."
  }
}
```

## 🔒 Segurança e Boas Práticas

### Tokens de Acesso

1. **Short-lived token** (1 hora): Obtido no OAuth inicial
2. **Long-lived token** (60 dias): Trocado automaticamente pelo backend
3. **Page token**: Usado para publicação (não expira enquanto a Página existir)

### Renovação de Tokens

- O backend armazena tokens long-lived (60 dias)
- **TODO**: Implementar renovação automática antes da expiração
- Usuário pode reconectar manualmente se o token expirar

### Dados Armazenados

Tabela `social_connections`:
- `access_token`: Token long-lived do usuário
- `page_access_token`: Token da Página (usado para publicar)
- `ig_user_id`: ID da conta Instagram Business
- `ig_username`: Nome de usuário do Instagram
- `token_expires_at`: Data de expiração do token

## 🐛 Troubleshooting

### Erro: "Nenhuma Página do Facebook encontrada"

**Causa**: Usuário não tem uma Página do Facebook vinculada ao Instagram.

**Solução**:
1. Criar uma Página no Facebook
2. Vincular ao Instagram: Configurações → Empresa → Página do Facebook

### Erro: "Nenhuma conta do Instagram Comercial encontrada"

**Causa**: Conta do Instagram é pessoal, não comercial.

**Solução**:
1. Converter para Conta Comercial ou Criador
2. Instagram → Configurações → Conta → Mudar tipo de conta

### Erro: "Meta API: (#200) Provide valid app ID"

**Causa**: `META_APP_ID` não configurado ou inválido.

**Solução**: Verificar variável de ambiente no Railway.

### Erro: "Meta API: (#100) Invalid OAuth 2.0 Access Token"

**Causa**: Token expirado ou inválido.

**Solução**: Usuário precisa reconectar a conta (desconectar e conectar novamente).

### Erro: "Timeout ao processar vídeo"

**Causa**: Vídeo muito grande ou processamento lento no Instagram.

**Solução**:
1. Reduzir tamanho/duração do vídeo
2. Tentar novamente após alguns minutos
3. Verificar se a URL do vídeo é pública e acessível

## 📊 Limites da API

### Rate Limits (por usuário)

- **Posts/Reels**: 25 por dia (limite do Instagram)
- **API calls**: 200 por hora (limite da Meta Graph API)

### Requisitos de Mídia

#### Imagens:
- Formato: JPG, PNG
- Tamanho: Máximo 8 MB
- Dimensões: Mínimo 320px, máximo 1080px (largura)
- Aspect ratio: 4:5 (vertical), 1.91:1 (horizontal), 1:1 (quadrado)

#### Vídeos/Reels:
- Formato: MP4, MOV
- Tamanho: Máximo 100 MB
- Duração: 3-90 segundos (Reels), até 60 minutos (vídeos IGTV)
- Aspect ratio: 9:16 (vertical recomendado para Reels)
- Codec: H.264, AAC audio
